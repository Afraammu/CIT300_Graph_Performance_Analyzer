# Data Structure and Graph Performance Analyzer

## Project Description

This is a Java-based console application developed for the CIT300 Data Structures and Algorithms assignment. It demonstrates common data structures, searching algorithms, graph traversal, and a basic performance comparison.

## Features

* Array operations: insert, delete, search, and display
* Stack operations: push, pop, peek, and display
* Queue operations: enqueue, dequeue, peek, and display
* Linked List operations: insert, delete, search, and display
* Searching algorithms: Linear Search and Binary Search
* Graph operations: add vertices, add edges, Breadth-First Search (BFS), and Depth-First Search (DFS)
* Performance comparison between Linear Search and Binary Search
* Input validation for menu selections

## Technologies Used

* Java
* Git
* GitHub
* Visual Studio Code

## How to Run

1. Install the Java Development Kit (JDK).

2. Open the project folder in Visual Studio Code.

3. Open the terminal in the project folder.

4. Compile the Java files:

   `javac *.java`

5. Run the application:

   `java Main`

## Project Structure

* `Main.java` – Main menu and application control
* `ArrayManager.java` – Array operations
* `StackManager.java` – Stack operations
* `QueueManager.java` – Queue operations
* `LinkedListManager.java` – Linked List operations
* `SearchingManager.java` – Searching algorithms
* `GraphManager.java` – Graph operations and traversal
* `PerformanceManager.java` – Searching performance comparison
* `.gitignore` – Excludes compiled Java class files
